Implementing Cicchini, Chopin, & Burr (2022) — Equations 1-19

Published

February 9, 2026

Introduction

Visual crowding — the inability to identify peripheral targets surrounded by nearby items — is traditionally viewed as a processing bottleneck. Cicchini, Chopin, & Burr (2022, Nature Communications) proposed a radical alternative: crowding is optimal Bayesian integration.

ImportantThe Core Claim

The visual system doesn’t blindly mix nearby items. It computes a weighted average of target and flanker information, where the weight depends on:

  1. Reliability of each source (noisy target → lean more on flankers)
  2. Similarity between items (different flankers → ignore them)

When flankers match the target, this averaging reduces noise — crowding actually helps.

The paper presents two models and two fitting functions:

Component Equations What it does
Ideal Observer (IO) Eq 1–11 Always integrates, weight decreases smoothly with difference
Causal Inference (CI) Eq 12–17 Adds a gate: integrate only if items likely share a common cause
Fitting functions Eq 18–19 DoG for bias, Gaussian for scatter — used to fit empirical data
TipWhat We’ll Build

By the end of this demo, you’ll have working R functions for every equation in the paper, and you’ll see how they produce the three key predictions: DoG bias, U-shaped scatter, and RMSE minimum at d = 0.

Part I: Ideal Observer Model (Eq 1–11)

The Model Setup

Consider a display with three items arranged radially in the periphery:

  • Target (T): The item the observer must report (e.g., its orientation)
  • Flanker 1 (F₁) and Flanker 2 (F₂): Neighboring items that may influence the report

Each item’s representation is noisy:

  • Target: perceived as \(T + \epsilon_T\), where \(\epsilon_T \sim \mathcal{N}(0, \sigma_T^2)\)
  • Flankers: perceived as \(F_i + \epsilon_{F_i}\), where \(\epsilon_{F_i} \sim \mathcal{N}(0, \sigma_F^2)\)
NoteWhat do σ_T and σ_F represent?

In the experiment, rounded ovals are hard to judge (\(\sigma \approx 13.2°\)) and elongated ovals are easy (\(\sigma \approx 10.0°\)). These are measured empirically from single-target trials, not assumed.

Equation 1: RMSE Decomposition

Total RMS error (\(E\)) can be decomposed into bias (\(B\)) and precision (scatter standard deviation: \(S\)), whose squares sum to give total squared error:

\[E = \sqrt{B^2 + S^2} \tag{1}\]

ImportantKey Equation

This decomposition is the foundation of the paper’s analysis. Crowding affects bias and scatter differently — you can’t see the full picture by measuring only one.

Concrete example: If bias = 3° and scatter = 4°, then RMSE = \(\sqrt{9 + 16}\) = 5°.

Bias (B) Scatter (S) RMSE (E)
0° 10° 10.0°
3° 4° 5.0°
5° 5° 7.1°
10° 0° 10.0°

Equation 2: General Weighted Response

The ideal response (\(R\)) is a weighted combination of target and flankers:

\[R = w_1 F_1 + w_2 F_2 + (1 - w_1 - w_2) T \tag{2}\]

The weights sum to 1, ensuring the response is a proper weighted average.

Equation 3: Equal-Weight Simplification

Since the two flankers had the same aspect ratio, they should be weighted equally (\(w_1 = w_2 = w\)):

\[R = w F_1 + w F_2 + (1 - 2w) T \tag{3}\]

NoteWhy equal weights?

Both flankers are at the same distance from the target and have the same shape (same σ). There’s no reason to treat one differently from the other.

Parameter table:

Symbol Meaning Range
\(w\) Weight per flanker 0 to ~0.33
\(1 - 2w\) Weight on target ~0.33 to 1
\(T\) Target orientation Degrees
\(F_1, F_2\) Flanker orientations Degrees

Equations 4–7: Deriving the Bias

Equation 4 — Mean response:

\[\mu_R = w(\mu_1 + \mu_2) + (1 - 2w)\mu_T \tag{4}\]

Equation 5 — Bias = mean response minus true target:

\[B = \mu_R - x_T = w(\mu_1 + \mu_2 - 2\mu_T) \tag{5}\]

Equation 6 — Define \(d\) as the average flanker–target difference:

\[d = \frac{\mu_1 + \mu_2}{2} - \mu_T \tag{6}\]

Equation 7 — Bias in terms of \(d\):

\[B = 2wd \tag{7}\]

NoteWhy is bias = 2wd?

Each flanker pulls the response by \(w \cdot d\) (weight times difference). Two flankers → \(2wd\). More weight → more pull. Larger difference → more pull. But since \(w\) decreases with \(d\) (Eq 10), the product \(2wd\) traces a derivative-of-Gaussian shape.

Concrete example: If \(w = 0.25\) and \(d = 10°\), then bias = \(2 \times 0.25 \times 10 = 5°\). The response is pulled 5° toward the flankers.

Code 
compute_bias <- function(w, d) {
  2 * w * d
}

Equation 8: Scatter

Since \(R\) is a weighted sum of independent random variables, its variance follows \(\text{Var}(aX + bY) = a^2\text{Var}(X) + b^2\text{Var}(Y)\):

\[S^2 = 2w^2 \sigma_F^2 + (1 - 2w)^2 \sigma_T^2 \tag{8}\]

NoteWhy are the coefficients squared?

Variance measures squared deviations. When you multiply a random variable by a constant \(a\), the variance is multiplied by \(a^2\), not \(a\). This is why \(w\) becomes \(w^2\) and \((1-2w)\) becomes \((1-2w)^2\).

Concrete example: If \(w = 0.25\), \(\sigma_T = 13°\), \(\sigma_F = 10°\):

  • Flanker contribution: \(2 \times 0.25^2 \times 100 = 12.5\)
  • Target contribution: \((1 - 0.5)^2 \times 169 = 42.25\)
  • Total: \(S = \sqrt{12.5 + 42.25} = \sqrt{54.75} = 7.4°\)

Compare to no flankers (\(w = 0\)): \(S = \sigma_T = 13°\). The flankers reduced scatter from 13° to 7.4°!

Code 
compute_scatter <- function(w, sigma_T, sigma_F) {
  sqrt(2 * w^2 * sigma_F^2 + (1 - 2 * w)^2 * sigma_T^2)
}

Equations 9–10: Optimal Weight

Equation 9 — RMSE² expanded:

\[E^2 = 4w^2 d^2 + 2w^2 \sigma_F^2 + (1 - 2w)^2 \sigma_T^2 \tag{9}\]

Code 
total_error_sq <- function(w, d, sigma_T, sigma_F) {
  4 * w^2 * d^2 + 2 * w^2 * sigma_F^2 + (1 - 4*w + 4*w^2) * sigma_T^2
}

Equation 10 — Minimizing \(E^2\) by setting \(dE^2/dw = 0\):

\[w_{opt} = \frac{\sigma_T^2}{2\sigma_T^2 + \sigma_F^2 + 2d^2} \tag{10}\]

ImportantKey Equation: Optimal Weight

This is the heart of the model. The weight balances three factors:

Factor Effect on \(w\) Intuition
Large \(\sigma_T\) (unreliable target) \(w\) increases Lean more on flankers
Large \(\sigma_F\) (unreliable flankers) \(w\) decreases Flankers aren’t helpful
Large \(d\) (different flankers) \(w\) decreases Flankers carry irrelevant info

Concrete examples:

Code 
optimal_weight <- function(sigma_T, sigma_F, d) {
  sigma_T^2 / (2 * sigma_T^2 + sigma_F^2 + 2 * d^2)
}

Equation 11: Regression to the Mean

The paper also found regression to the mean (responses pulled toward 45°). The full response equation adds a regression factor \(\rho\) and a sub-optimality scaling \(\alpha\):

\[R = \alpha \rho (w F_1 + w F_2 + (1 - 2w) T) + (1 - \rho) \cdot 45 \tag{11}\]

WarningWhen to use Eq 11 vs Eq 3

Eq 11 is for fitting real data (with regression to the mean and sub-optimal behaviour). In our simulations below, we use the pure model (Eq 3 + 10) to show the core predictions without these corrections.

RMSE Function

compute_rmse <- function(bias, scatter) {

Part II: Causal Inference Model (Eq 12–17)

The basic ideal observer always integrates — weight \(w\) decreases smoothly with \(d\), but never reaches zero. There is no mechanism to decide whether to integrate. The Causal Inference (CI) model adds a gating step: integrate only when target and flankers likely share a common cause.

Equation 12: Maximum Likelihood Weight

When two sources are known to come from the same cause, the optimal weight for source \(A\) is:

\[w^{max}_A = \frac{\sigma_B^2}{\sigma_A^2 + \sigma_B^2} \tag{12}\]

NoteHow does this differ from Eq 10?

Eq 10 weights one flanker among three items (target + 2 flankers) and includes a \(d^2\) term. Eq 12 is the classic two-source MLE weight — no \(d^2\) because the common cause assumption guarantees \(d = 0\).

Code 
mle_weight <- function(sigma_A, sigma_B) {
  sigma_B^2 / (sigma_A^2 + sigma_B^2)
}

Concrete example: If \(\sigma_T = 13°\) and \(\sigma_F = 10°\), then \(w_{max} = 100 / (169 + 100) = 0.372\). The more reliable flanker gets 37% weight.

Equations 13–14: Common Cause Probability

Equation 13 — Full Bayesian with prior \(P(S) = \mathcal{N}(\mu_P, \sigma_P^2)\):

\[P(A, B \mid C = 1) \propto \exp\!\left(-\frac{1}{2} \cdot \frac{(\mu_A - \mu_B)^2 \sigma_P^2 + (\mu_A - \mu_P)^2 \sigma_B^2 + (\mu_B - \mu_P)^2 \sigma_A^2}{\sigma_A^2 \sigma_B^2 + \sigma_A^2 \sigma_P^2 + \sigma_B^2 \sigma_P^2}\right) \tag{13}\]

The three numerator terms penalize different mismatches:

Term Meaning
\((\mu_A - \mu_B)^2 \sigma_P^2\) A and B differ from each other
\((\mu_A - \mu_P)^2 \sigma_B^2\) A differs from the prior
\((\mu_B - \mu_P)^2 \sigma_A^2\) B differs from the prior

Equation 14 — Simplified with flat prior (\(\sigma_P^2 \to \infty\)):

\[P(A, B \mid C = 1) \propto \exp\!\left(-\frac{(\mu_A - \mu_B)^2}{2(\sigma_A^2 + \sigma_B^2)}\right) \tag{14}\]

NoteWhy does a flat prior simplify things?

When \(\sigma_P^2 \to \infty\), it dominates in both numerator and denominator. The first term \((\mu_A - \mu_B)^2 \sigma_P^2\) dominates the numerator; \(\sigma_P^2(\sigma_A^2 + \sigma_B^2)\) dominates the denominator. They cancel, leaving only: how different are A and B from each other, relative to their combined noise?

Code 
prob_common_cause <- function(d, sigma_A, sigma_B) {
  exp(-d^2 / (2 * (sigma_A^2 + sigma_B^2)))
}

Concrete example: If \(\sigma_T = 13.2°\), \(\sigma_F = 10°\), and \(d = 0\): P = \(\exp(0) = 1\). If \(d = 20°\): P = \(\exp(-400 / (2 \times 274.24)) = \exp(-0.73) = 0.48\). At \(d = 45°\): P = \(\exp(-2025/548.48) = \exp(-3.69) = 0.025\).

Equation 15: CI Model Bias

In Cicchini et al.’s experiment, the two sources are the flanker compound (\(\sigma_C^2 = \sigma_F^2/2\)) and the target. Combining Eqs 12 and 14:

\[B = \frac{\sigma_T^2}{\sigma_C^2 + \sigma_T^2} \cdot \exp\!\left(-\frac{d^2}{2(\sigma_C^2 + \sigma_T^2)}\right) \cdot d \tag{15}\]

Code 
ci_bias <- function(d, sigma_T, sigma_F) {
  sigma_C2 <- sigma_F^2 / 2
  w_max <- sigma_T^2 / (sigma_C2 + sigma_T^2)
  p_cc <- exp(-d^2 / (2 * (sigma_C2 + sigma_T^2)))
  w_max * p_cc * d
}

Equation 16: CI Bias with Free Parameters

For fitting real data, two free parameters (\(\beta\) for amplitude, \(\gamma\) for breadth) plus regression factor \(\rho = 0.67\):

\[B = \beta \rho \cdot \frac{\sigma_T^2}{\sigma_C^2 + \sigma_T^2} \cdot \exp\!\left(-\frac{d^2}{2\gamma^2(\sigma_C^2 + \sigma_T^2)}\right) \cdot d \tag{16}\]

Code 
ci_bias_full <- function(d, sigma_T, sigma_F, beta, rho, gamma) {
  sigma_C2 <- sigma_F^2 / 2
  w_ratio <- sigma_T^2 / (sigma_C2 + sigma_T^2)
  p_cc <- exp(-d^2 / (2 * gamma^2 * (sigma_C2 + sigma_T^2)))
  beta * rho * w_ratio * p_cc * d
}

Equation 17: Product of Two Gaussians

The product of two Gaussians with different means has a peak at:

\[\frac{1}{2\pi \sigma_A \sigma_B} \exp\!\left(-\frac{(\mu_A - \mu_B)^2}{2(\sigma_A^2 + \sigma_B^2)}\right) \tag{17}\]

This embeds the same Gaussian dependency on \(|\mu_A - \mu_B|\) as Eq 14 — the same gating behaviour emerges whether you compute the common-cause probability (Bayesian) or the distribution overlap (product).

Part III: Model Fitting Functions (Eq 18–19)

Cicchini et al. fit their empirical data using a derivative-of-Gaussian for bias and a Gaussian for scatter.

Equation 18: Derivative-of-Gaussian Fit for Bias

Bias was fitted by a DoG — a Gaussian of width \(s\) multiplied by a straight line of slope \(a\):

\[B = a \cdot (\theta - m) \cdot \exp\!\left(-\frac{(\theta - m)^2}{s^2}\right) + b \tag{18}\]

Parameter Meaning
\(a\) Weight/amplitude (slope of linear component)
\(m\) Centre of the DoG
\(s\) Width of the Gaussian window
\(b\) Vertical offset
Code 
dog_fit <- function(theta, a, m, s, b) {
  a * (theta - m) * exp(-(theta - m)^2 / s^2) + b
}

Equation 19: Gaussian Fit for Scatter

\[S = a \cdot \exp\!\left(-\frac{(\theta - m)^2}{s^2}\right) + b \tag{19}\]

Parameter Meaning
\(a\) Amplitude of the Gaussian dip (negative for U-shape)
\(m\) Centre
\(s\) Width (yoked to Eq 18)
\(b\) Baseline scatter at large differences
NoteWhy yoke the width parameter?

Since bias and scatter likely originate from the same integration process, the width \(s\) is shared between Eq 18 and 19. This reduces free parameters and ensures both curves reflect the same integration window.

Code 
gaussian_scatter_fit <- function(theta, a, m, s, b) {
  a * exp(-(theta - m)^2 / s^2) + b
}

## Introduction

Visual crowding — the inability to identify peripheral targets surrounded by nearby items — is traditionally viewed as a processing bottleneck. Cicchini, Chopin, & Burr (2022, *Nature Communications*) proposed a radical alternative: crowding is **optimal Bayesian integration**.

::: {.callout-important title="The Core Claim"}
The visual system doesn't blindly mix nearby items. It computes a **weighted average** of target and flanker information, where the weight depends on:

1. **Reliability** of each source (noisy target → lean more on flankers)
2. **Similarity** between items (different flankers → ignore them)

When flankers match the target, this averaging **reduces noise** — crowding actually *helps*.
:::

The paper presents two models and two fitting functions:

| Component | Equations | What it does |
|-----------|----------|--------------|
| **Ideal Observer (IO)** | Eq 1–11 | Always integrates, weight decreases smoothly with difference |
| **Causal Inference (CI)** | Eq 12–17 | Adds a gate: integrate only if items likely share a common cause |
| **Fitting functions** | Eq 18–19 | DoG for bias, Gaussian for scatter — used to fit empirical data |

::: {.callout-tip title="What We'll Build"}
By the end of this demo, you'll have working R functions for every equation in the paper, and you'll see how they produce the three key predictions: **DoG bias**, **U-shaped scatter**, and **RMSE minimum at d = 0**.
:::

# Part I: Ideal Observer Model (Eq 1–11)

## The Model Setup

Consider a display with three items arranged radially in the periphery:

- **Target (T):** The item the observer must report (e.g., its orientation)
- **Flanker 1 (F₁) and Flanker 2 (F₂):** Neighboring items that may influence the report

Each item's representation is noisy:

- Target: perceived as $T + \epsilon_T$, where $\epsilon_T \sim \mathcal{N}(0, \sigma_T^2)$
- Flankers: perceived as $F_i + \epsilon_{F_i}$, where $\epsilon_{F_i} \sim \mathcal{N}(0, \sigma_F^2)$

::: {.callout-note title="What do σ_T and σ_F represent?"}
In the experiment, **rounded ovals** are hard to judge ($\sigma \approx 13.2°$) and **elongated ovals** are easy ($\sigma \approx 10.0°$). These are measured empirically from single-target trials, not assumed.
:::

## Equation 1: RMSE Decomposition

Total RMS error ($E$) can be decomposed into bias ($B$) and precision (scatter standard deviation: $S$), whose squares sum to give total squared error:

$$E = \sqrt{B^2 + S^2} \tag{1}$$

::: {.callout-important title="Key Equation"}
This decomposition is the foundation of the paper's analysis. Crowding affects bias and scatter differently — you can't see the full picture by measuring only one.
:::

**Concrete example:** If bias = 3° and scatter = 4°, then RMSE = $\sqrt{9 + 16}$ = 5°.

| Bias (B) | Scatter (S) | RMSE (E) |
|----------|-------------|----------|
| 0° | 10° | 10.0° |
| 3° | 4° | 5.0° |
| 5° | 5° | 7.1° |
| 10° | 0° | 10.0° |

## Equation 2: General Weighted Response

The ideal response ($R$) is a weighted combination of target and flankers:

$$R = w_1 F_1 + w_2 F_2 + (1 - w_1 - w_2) T \tag{2}$$

The weights sum to 1, ensuring the response is a proper weighted average.

## Equation 3: Equal-Weight Simplification

Since the two flankers had the same aspect ratio, they should be weighted equally ($w_1 = w_2 = w$):

$$R = w F_1 + w F_2 + (1 - 2w) T \tag{3}$$

::: {.callout-note title="Why equal weights?"}
Both flankers are at the same distance from the target and have the same shape (same σ). There's no reason to treat one differently from the other.
:::

**Parameter table:**

| Symbol | Meaning | Range |
|--------|---------|-------|
| $w$ | Weight per flanker | 0 to ~0.33 |
| $1 - 2w$ | Weight on target | ~0.33 to 1 |
| $T$ | Target orientation | Degrees |
| $F_1, F_2$ | Flanker orientations | Degrees |

## Equations 4–7: Deriving the Bias

**Equation 4** — Mean response:

$$\mu_R = w(\mu_1 + \mu_2) + (1 - 2w)\mu_T \tag{4}$$

**Equation 5** — Bias = mean response minus true target:

$$B = \mu_R - x_T = w(\mu_1 + \mu_2 - 2\mu_T) \tag{5}$$

**Equation 6** — Define $d$ as the average flanker–target difference:

$$d = \frac{\mu_1 + \mu_2}{2} - \mu_T \tag{6}$$

**Equation 7** — Bias in terms of $d$:

$$B = 2wd \tag{7}$$

::: {.callout-note title="Why is bias = 2wd?"}
Each flanker pulls the response by $w \cdot d$ (weight times difference). Two flankers → $2wd$. More weight → more pull. Larger difference → more pull. But since $w$ decreases with $d$ (Eq 10), the product $2wd$ traces a **derivative-of-Gaussian** shape.
:::

**Concrete example:** If $w = 0.25$ and $d = 10°$, then bias = $2 \times 0.25 \times 10 = 5°$. The response is pulled 5° toward the flankers.

```{r}
#| label: bias-function
compute_bias <- function(w, d) {
  2 * w * d
}
```

## Equation 8: Scatter

Since $R$ is a weighted sum of independent random variables, its variance follows $\text{Var}(aX + bY) = a^2\text{Var}(X) + b^2\text{Var}(Y)$:

$$S^2 = 2w^2 \sigma_F^2 + (1 - 2w)^2 \sigma_T^2 \tag{8}$$

::: {.callout-note title="Why are the coefficients squared?"}
Variance measures **squared** deviations. When you multiply a random variable by a constant $a$, the variance is multiplied by $a^2$, not $a$. This is why $w$ becomes $w^2$ and $(1-2w)$ becomes $(1-2w)^2$.
:::

**Concrete example:** If $w = 0.25$, $\sigma_T = 13°$, $\sigma_F = 10°$:

- Flanker contribution: $2 \times 0.25^2 \times 100 = 12.5$
- Target contribution: $(1 - 0.5)^2 \times 169 = 42.25$
- Total: $S = \sqrt{12.5 + 42.25} = \sqrt{54.75} = 7.4°$

Compare to no flankers ($w = 0$): $S = \sigma_T = 13°$. The flankers **reduced scatter from 13° to 7.4°**!

```{r}
#| label: scatter-function
compute_scatter <- function(w, sigma_T, sigma_F) {
  sqrt(2 * w^2 * sigma_F^2 + (1 - 2 * w)^2 * sigma_T^2)
}
```

## Equations 9–10: Optimal Weight

**Equation 9** — RMSE² expanded:

$$E^2 = 4w^2 d^2 + 2w^2 \sigma_F^2 + (1 - 2w)^2 \sigma_T^2 \tag{9}$$

```{r}
#| label: total-error-sq
total_error_sq <- function(w, d, sigma_T, sigma_F) {
  4 * w^2 * d^2 + 2 * w^2 * sigma_F^2 + (1 - 4*w + 4*w^2) * sigma_T^2
}
```

**Equation 10** — Minimizing $E^2$ by setting $dE^2/dw = 0$:

$$w_{opt} = \frac{\sigma_T^2}{2\sigma_T^2 + \sigma_F^2 + 2d^2} \tag{10}$$

::: {.callout-important title="Key Equation: Optimal Weight"}
This is the heart of the model. The weight balances three factors:

| Factor | Effect on $w$ | Intuition |
|--------|--------------|-----------|
| Large $\sigma_T$ (unreliable target) | $w$ increases | Lean more on flankers |
| Large $\sigma_F$ (unreliable flankers) | $w$ decreases | Flankers aren't helpful |
| Large $d$ (different flankers) | $w$ decreases | Flankers carry irrelevant info |
:::

**Concrete examples:**

```{r}
#| label: optimal-weight
optimal_weight <- function(sigma_T, sigma_F, d) {
  sigma_T^2 / (2 * sigma_T^2 + sigma_F^2 + 2 * d^2)
}
```

## Equation 11: Regression to the Mean

The paper also found regression to the mean (responses pulled toward 45°). The full response equation adds a regression factor $\rho$ and a sub-optimality scaling $\alpha$:

$$R = \alpha \rho (w F_1 + w F_2 + (1 - 2w) T) + (1 - \rho) \cdot 45 \tag{11}$$

::: {.callout-warning title="When to use Eq 11 vs Eq 3"}
Eq 11 is for **fitting real data** (with regression to the mean and sub-optimal behaviour). In our simulations below, we use the **pure model** (Eq 3 + 10) to show the core predictions without these corrections.
:::

# Part II: Causal Inference Model (Eq 12–17)

The basic ideal observer **always** integrates — weight $w$ decreases smoothly with $d$, but never reaches zero. There is no mechanism to decide *whether* to integrate. The Causal Inference (CI) model adds a **gating step**: integrate only when target and flankers likely share a common cause.

## Equation 12: Maximum Likelihood Weight

When two sources are known to come from the same cause, the optimal weight for source $A$ is:

$$w^{max}_A = \frac{\sigma_B^2}{\sigma_A^2 + \sigma_B^2} \tag{12}$$

::: {.callout-note title="How does this differ from Eq 10?"}
Eq 10 weights one flanker among three items (target + 2 flankers) and includes a $d^2$ term. Eq 12 is the classic **two-source** MLE weight — no $d^2$ because the common cause assumption guarantees $d = 0$.
:::

```{r}
#| label: mle-weight
mle_weight <- function(sigma_A, sigma_B) {
  sigma_B^2 / (sigma_A^2 + sigma_B^2)
}
```

**Concrete example:** If $\sigma_T = 13°$ and $\sigma_F = 10°$, then $w_{max} = 100 / (169 + 100) = 0.372$. The more reliable flanker gets 37% weight.

## Equations 13–14: Common Cause Probability

**Equation 13** — Full Bayesian with prior $P(S) = \mathcal{N}(\mu_P, \sigma_P^2)$:

$$P(A, B \mid C = 1) \propto \exp\!\left(-\frac{1}{2} \cdot \frac{(\mu_A - \mu_B)^2 \sigma_P^2 + (\mu_A - \mu_P)^2 \sigma_B^2 + (\mu_B - \mu_P)^2 \sigma_A^2}{\sigma_A^2 \sigma_B^2 + \sigma_A^2 \sigma_P^2 + \sigma_B^2 \sigma_P^2}\right) \tag{13}$$

The three numerator terms penalize different mismatches:

| Term | Meaning |
|------|---------|
| $(\mu_A - \mu_B)^2 \sigma_P^2$ | A and B differ from **each other** |
| $(\mu_A - \mu_P)^2 \sigma_B^2$ | A differs from the **prior** |
| $(\mu_B - \mu_P)^2 \sigma_A^2$ | B differs from the **prior** |

**Equation 14** — Simplified with flat prior ($\sigma_P^2 \to \infty$):

$$P(A, B \mid C = 1) \propto \exp\!\left(-\frac{(\mu_A - \mu_B)^2}{2(\sigma_A^2 + \sigma_B^2)}\right) \tag{14}$$

::: {.callout-note title="Why does a flat prior simplify things?"}
When $\sigma_P^2 \to \infty$, it dominates in both numerator and denominator. The first term $(\mu_A - \mu_B)^2 \sigma_P^2$ dominates the numerator; $\sigma_P^2(\sigma_A^2 + \sigma_B^2)$ dominates the denominator. They cancel, leaving only: how different are A and B from each other, relative to their combined noise?
:::

```{r}
#| label: common-cause-prob
prob_common_cause <- function(d, sigma_A, sigma_B) {
  exp(-d^2 / (2 * (sigma_A^2 + sigma_B^2)))
}
```

**Concrete example:** If $\sigma_T = 13.2°$, $\sigma_F = 10°$, and $d = 0$: P = $\exp(0) = 1$. If $d = 20°$: P = $\exp(-400 / (2 \times 274.24)) = \exp(-0.73) = 0.48$. At $d = 45°$: P = $\exp(-2025/548.48) = \exp(-3.69) = 0.025$.

## Equation 15: CI Model Bias

In Cicchini et al.'s experiment, the two sources are the **flanker compound** ($\sigma_C^2 = \sigma_F^2/2$) and the **target**. Combining Eqs 12 and 14:

$$B = \frac{\sigma_T^2}{\sigma_C^2 + \sigma_T^2} \cdot \exp\!\left(-\frac{d^2}{2(\sigma_C^2 + \sigma_T^2)}\right) \cdot d \tag{15}$$

```{r}
#| label: ci-bias-function
ci_bias <- function(d, sigma_T, sigma_F) {
  sigma_C2 <- sigma_F^2 / 2
  w_max <- sigma_T^2 / (sigma_C2 + sigma_T^2)
  p_cc <- exp(-d^2 / (2 * (sigma_C2 + sigma_T^2)))
  w_max * p_cc * d
}
```

## Equation 16: CI Bias with Free Parameters

For fitting real data, two free parameters ($\beta$ for amplitude, $\gamma$ for breadth) plus regression factor $\rho = 0.67$:

$$B = \beta \rho \cdot \frac{\sigma_T^2}{\sigma_C^2 + \sigma_T^2} \cdot \exp\!\left(-\frac{d^2}{2\gamma^2(\sigma_C^2 + \sigma_T^2)}\right) \cdot d \tag{16}$$

```{r}
#| label: ci-bias-full
ci_bias_full <- function(d, sigma_T, sigma_F, beta, rho, gamma) {
  sigma_C2 <- sigma_F^2 / 2
  w_ratio <- sigma_T^2 / (sigma_C2 + sigma_T^2)
  p_cc <- exp(-d^2 / (2 * gamma^2 * (sigma_C2 + sigma_T^2)))
  beta * rho * w_ratio * p_cc * d
}
```

## Equation 17: Product of Two Gaussians

The product of two Gaussians with different means has a peak at:

$$\frac{1}{2\pi \sigma_A \sigma_B} \exp\!\left(-\frac{(\mu_A - \mu_B)^2}{2(\sigma_A^2 + \sigma_B^2)}\right) \tag{17}$$

This embeds the same Gaussian dependency on $|\mu_A - \mu_B|$ as Eq 14 — the same gating behaviour emerges whether you compute the common-cause probability (Bayesian) or the distribution overlap (product).

# Part III: Model Fitting Functions (Eq 18–19)

Cicchini et al. fit their empirical data using a derivative-of-Gaussian for bias and a Gaussian for scatter.

## Equation 18: Derivative-of-Gaussian Fit for Bias

Bias was fitted by a DoG — a Gaussian of width $s$ multiplied by a straight line of slope $a$:

$$B = a \cdot (\theta - m) \cdot \exp\!\left(-\frac{(\theta - m)^2}{s^2}\right) + b \tag{18}$$

| Parameter | Meaning |
|-----------|---------|
| $a$ | Weight/amplitude (slope of linear component) |
| $m$ | Centre of the DoG |
| $s$ | Width of the Gaussian window |
| $b$ | Vertical offset |

```{r}
#| label: dog-fit-function
dog_fit <- function(theta, a, m, s, b) {
  a * (theta - m) * exp(-(theta - m)^2 / s^2) + b
}
```

## Equation 19: Gaussian Fit for Scatter

$$S = a \cdot \exp\!\left(-\frac{(\theta - m)^2}{s^2}\right) + b \tag{19}$$

| Parameter | Meaning |
|-----------|---------|
| $a$ | Amplitude of the Gaussian dip (negative for U-shape) |
| $m$ | Centre |
| $s$ | Width (**yoked** to Eq 18) |
| $b$ | Baseline scatter at large differences |

::: {.callout-note title="Why yoke the width parameter?"}
Since bias and scatter likely originate from the same integration process, the width $s$ is shared between Eq 18 and 19. This reduces free parameters and ensures both curves reflect the same integration window.
:::

```{r}
#| label: gaussian-scatter-function
gaussian_scatter_fit <- function(theta, a, m, s, b) {
  a * exp(-(theta - m)^2 / s^2) + b
}
```
