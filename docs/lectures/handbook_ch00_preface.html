Handbook Preface: Why Math in Psychology?

New Handbook of Mathematical Psychology Vol.3

Based on Ashby, Colonius, & Dzhafarov (2023)

The Core Message

Mathematics in psychology is NOT about computing.

It is about:

  • Conceptual clarity
  • Avoiding conceptual confusions
  • Explicating hidden assumptions

“Before we can compute, we need to explicate the hidden assumptions we make, and often when we do this we find out these assumptions are not all that compelling.”

The Dupin Example

Edgar Allan Poe’s character Mr. Dupin (1845):

“Two motives, each of a given value, have not, necessarily, a value when united, equal to the sum of their values apart.”

Hidden assumptions:

  • D1: Motives A and B can be combined
  • D2-D3: Each can be assigned a real number value
  • D4: Combination = sum of values (a + b)
  • D5: Empirically, c ≠ a + b

Conclusion: Math doesn’t apply? No! The hidden assumption D4 is wrong.

Order Effects in Logic

Classical logic: A ∧ B ≡ B ∧ A (commutative)

But: Order of presentation matters empirically!

Hidden assumption: “A presented first, B second” = A ∧ B

Solution: Use positional labels:

  • A₁ ∧ B₂ (A first, B second)
  • A₂ ∧ B₁ (A second, B first)

These are different propositions. Commutativity preserved: A₁ ∧ B₂ ≡ B₂ ∧ A₁

Representational Theory of Measurement

Entities are measured on specific scales:

Scale Transformation Example
Ordinal Monotonic Rankings
Interval f(x) = ax + b Temperature (°C, °F)
Ratio f(x) = kx Length, mass

Ratio scale: Any two valid measurement functions f and g satisfy:

\[f(x) = k \cdot g(x)\]

for some positive constant k.

Luce’s Principle of Theory Construction

Setup:

  • x = stimulus magnitude (ratio scale)
  • s = sensation magnitude (ratio scale)
  • ψ = psychophysical function: s = ψ(x)

Key idea: If we rescale stimulus by factor k:

\[x' = kx\]

Then sensation should also rescale by some factor c = K(k):

\[s' = K(k) \cdot s\]

The Functional Equation

From Luce’s principle:

\[\psi(kx) = K(k) \cdot \psi(x)\]

The only solution (for all positive k and x):

\[\psi(x) = b \cdot x^\beta\] \[K(k) = k^\beta\]

Surprising conclusion: Only power functions satisfy scale invariance!

But Wait… Fechner’s Law

Fechner (1861) proposed:

\[s = s_0 \cdot \log\left(\frac{x}{x_0}\right)\]

This is NOT a power function. How can it exist?

Rozeboom (1962) found the hidden assumption:

Luce assumed no dimensional constants.

What Are Dimensional Constants?

A dimensional constant is measured in the same units as your variable:

  • x₀ = threshold stimulus (same units as x)
  • s₀ = baseline sensation (same units as s)

When you rescale x → kx, you must also rescale x₀ → kx₀:

\[\frac{kx}{kx_0} = \frac{x}{x_0}\]

The ratio is unchanged - automatically scale-invariant!

The Resolution

With dimensional constants, any function works:

\[s = s_0 \cdot \psi\left(\frac{x}{x_0}\right)\]

Approach Result
Luce (no dim. constants) Only power functions
Rozeboom (with dim. constants) Any function of x/x₀

Luce accepted this criticism and withdrew his “principle” (Luce, 1962).

The Lesson

Hidden assumptions can exist even in rigorous treatments.

  1. Someone makes a mathematical argument
  2. The conclusion seems surprising or restrictive
  3. Upon closer inspection: hidden assumption
  4. Making it explicit resolves the puzzle

Math forces us to state assumptions clearly.

Summary

Why math in psychology?

  1. Conceptual clarity - not computation
  2. Explicate hidden assumptions - before we can calculate
  3. Avoid false constraints - like Luce’s “only power functions”
  4. Enable new questions - dimensional constants, scale types

“The value of mathematical thinking is not in the calculations themselves, but in forcing us to state our assumptions clearly.”
