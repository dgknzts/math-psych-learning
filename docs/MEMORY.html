# Claude Memory - Math Psych Learning Project

## Project Overview
A personal learning hub for mathematical psychology. User is studying textbooks and articles, creating lectures, demos, exercises, and exams as they learn. Published as GitHub Pages site.

## User Preferences
- **Coding language**: R
- **Slides format**: Quarto (.qmd)
- **Notes**: Handwritten, shared via photo/scan
- **Organization**: Flat files with prefix naming (e.g., `handbook_ch01_visual.R`)

## Directory Structure
```
handbook_of_math_psych/
├── pdf/                    # Private - original PDFs
│   └── handbook/           # Split chapter PDFs
├── notes/                  # Private - handwritten notes
├── demos/                  # R code demos
├── lectures/               # Quarto slides
├── exercises/              # Practice problems
│   └── solutions/
├── exams/                  # Self-assessment
│   └── keys/
└── docs/                   # Rendered website
```

## Naming Convention
- `handbook_preface` - Handbook preface
- `handbook_ch01_visual` - Handbook Chapter 1
- `ratcliff_2016` - Article by Ratcliff 2016
- Use categories in YAML for cross-linking (e.g., `categories: [learning-models, bayesian]`)

## Workflow Per Chapter/Article
1. User tells Claude which section they're reading
2. Claude reads PDF for context
3. When user hits a formula → code it in R together
4. User takes handwritten notes
5. User shares notes photo → Claude drafts Quarto slides
6. Create exercises together
7. Create exam questions
8. Claude quizzes user

## Current Sources
- **handbook** - New Handbook of Mathematical Psychology (Ashby et al., 2023)
  - 10 chapters + preface
  - PDFs split and stored in pdf/handbook/

## GitHub
- Repo: https://github.com/dgknzts/math-psych-learning
- Site: https://dgknzts.github.io/math-psych-learning/
- Deploy: `quarto render` then push docs/

## Key Decisions Made
- Flat file structure (not nested by source)
- Each chapter = standalone unit
- Cross-link via Quarto categories
- PDFs and notes gitignored (private)
- Solutions and exam keys are public
